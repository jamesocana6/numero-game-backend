Models
player {
    socketId: string,              // Crucial for routing events back to this specific user
    username: string, 
    userId: string,                // The MongoDB _id of the logged-in user (null if anonymous/guest)
    ready: boolean, 
    score: number, 
    numTiles: Array(number),       // Their current, unique board state
    undoArray: Array(Array(number)),// History stack for the Undo button
    selfBuzzerActive: boolean
}
game state {
    roomId: string,                // Matches the URL or join code
    status: string,                // 'lobby', 'in-progress', 'finished'
    mode: string,                  // 'time-trial', 'buzzer'
    timer: number,                 // Server-authoritative countdown clock
    scoreToWin: number,            // E.g., first to 5 points
    initialNumTiles: Array(number),// The starting tiles for the current round
    target: number
}


client events {
    join room: { roomId: string, username: string }
    leave room: { roomId: string }
    quick match: { username: string, mode: string }
    ready: { roomId: string }
    submit move: { roomId: string, index1: number, index2: number, operation: string }
    reset board / undo move: { roomId: string }
    buzzer click (BUZZER ONLY): { roomId: string }
}

server events {
    waiting for opponent: {}
    join error: { message: string }
    game start (Sends puzzle #1): { state: gameState, players: Array(player) }
    board updated: { socketId: string, numTiles: Array(number) }
    invalid move: { message: string }
    score updated (Sends puzzle #2, #3, etc.): { scores: Object, newInitialNumTiles: Array, newTarget: number }
    game over: { winnerId: string, reason: string }
    opponent disconnected: { socketId: string }
    timer sync: { timeRemaining: number }
    buzzer clicked (BUZZER ONLY): { activeSocketId: string }
}

// MongoDB User Schema
const userSchema = new mongoose.Schema({
    username: String,
    passwordHash: String, // Or OAuth tokens
    stats: {
        wins: { type: Number, default: 0 },
        losses: { type: Number, default: 0 },
        gamesPlayed: { type: Number, default: 0 }
    }
});

UPDATING MONGO FLOW
Here is what the flow looks like on the server:
-Player A scores the final point.
-Server detects the win in the submit move handler.
-Server checks if the winner has an account: if (winner.userId) { ... }
-Server updates MongoDB: It uses Mongoose to find the user by userId and increments their wins: $inc: { "stats.wins": 1 }.
-Server emits game over to the room, ending the match.
